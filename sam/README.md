# 让 102 话机显示你自己的 Claude Code

装好以后，你笔记本上的 Claude Code 要你批准命令、或者问你选择题时，会推到你桌上那台思科话机（分机 102）上响铃，你直接在话机上按 Allow / Deny 或点选项就行，不用守在电脑前。话机上也能看到你几个会话的状态。

分两步装：**先装 Mac mini（常开的那台），再装笔记本**。两边都要在家里的网络上。

---

## 第一步：Mac mini

1. 把 `sam-phone-hub.zip` 拷到 Mac mini 上，双击解压。
2. 打开「终端」，把解压出来的文件夹拖进终端窗口前先输入 `cd `（cd 后面有个空格），回车。也就是进到这个文件夹里。
3. 运行：

   ```bash
   bash install-hub.sh
   ```

   第一次可能会弹出“安装命令行开发者工具”，点安装，装完再运行一次上面这条。
4. 装好后屏幕上会显示两样东西：
   - **这台 Mac mini 的 IP**：发给 mo，mo 那边要把 102 话机指到你这台机器上。
   - **一把密钥**（一长串字母数字）：下一步在笔记本上要用。这把密钥只给你自己的笔记本用，别发给别人。

如果系统弹窗问“python 想查找和连接本地网络上的设备”，点**允许**。没弹窗但后面话机没反应的话，去「系统设置 → 隐私与安全性 → 本地网络」，把 python 打开。

它会开机自动运行，以后不用管。

## 第二步：笔记本

1. 把同一个 zip 拷到笔记本上，解压，在终端里 `cd` 进这个文件夹（同上）。
2. 运行：

   ```bash
   bash install-hook.sh
   ```

   如果 Mac mini 的 IP 不是 192.168.1.30，就把 IP 写在后面，例如 `bash install-hook.sh 192.168.1.31`。
3. 它会让你粘贴密钥：把第一步显示的那把密钥粘贴进去，回车（粘贴时屏幕上不显示，是正常的）。
4. 看到“装好了，Mac mini 上的 phone-hub 能连上”就成功了。
5. **新开一个 Claude Code 会话**，设置才会生效。

它会把原来的 Claude Code 设置先备份一份（`~/.claude/settings.json.bak-phone-时间`），只加电话相关的几条，你原有的设置不会动。

## 用法

- 话机上按「服务」按钮（地球图标）→ Claude Code 菜单：状态面板、待批准、消息、模式切换。
- **两种模式**：
  - **离开（AWAY）**：批准和选择题推到话机上响铃。电脑上同时也会弹出来，哪边先答算哪边。
  - **在座位（DESK）**：全部只在电脑上，话机不响。
  - 在面板上按 Mode 切换，会先问你确认，按第 3 个键 Switch 才真的切换。
- 你正在电脑上看着的那个会话（Claude 窗口在最前面、3 分钟内动过键盘鼠标），它的批准和提问只在电脑上弹，不会推到话机。
- 改文件（Write / Edit）这类内容太长、话机显示不全的请求，只在电脑上批准。
- 话机右下角的「Mo」键是快捷拨号，直接打给 mo（101）。

## 出问题时

- 话机上点了没反应、或者一直不推：先确认 Mac mini 开着、笔记本连着家里的网络（不在家时连不上，只会在电脑上弹窗，不影响用 Claude Code）。
- Mac mini 上的日志：`~/phone-hub/phone_hub.log`。
- 想停掉：在 Mac mini 上运行 `launchctl bootout gui/$(id -u)/com.sam.phone-hub`。
- 想在笔记本上卸掉：把 `~/.claude/settings.json` 里含 `phone_hook.py` 的几段删掉，或者用安装时备份的那份换回去。
